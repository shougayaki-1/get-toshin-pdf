# get-toshin-pdf

東進学力POS「過去問演習講座・共通テスト対策」の問題PDFを、**許可された個人利用の範囲で**取得・2-in-1変換・命名・ローカル保存するためのNode.jsツールです。

> GUIまたはCLIで候補を選び、一括取得できます。年度別は一覧を自動で開き、大問別は対象の分野までブラウザで開いてから選択します。

## できること

- Playwrightの専用ブラウザを開く。ログインは**本人がブラウザ上で操作**。
- `MondaiKaitoInsatsu` 画面に表示される `Contents/GetMondaiPdf?daimonId=...` リンクを検出し、認証済みのブラウザ文脈でPDF本体を取得。
- PDFのシグネチャを検証し、SHA-256で重複排除。途中中断しても取得済みデータを保持。原本だけが残った場合は、同じPDFの再取得時に履歴へ復旧します。
- 既存の [chrome-extension-2-in-1](https://github.com/shougayaki-1/chrome-extension-2-in-1) と同様のロジックで左右2ページを1枚に配置。
- **国語は右→左、それ以外は左→右**。元ページの回転・切り抜き範囲・安全余白を考慮。
- 科目・年度・回次を指定して自動命名。機密性のあるURLクエリや認証情報は記録しません。

## セットアップ

Node.js 20以上が必要です。

```bash
git clone git@github.com:shougayaki-1/get-toshin-pdf.git
cd get-toshin-pdf
npm install
npx playwright install chromium
```

### 1. 問題PDFの取得

```bash
npm run capture -- --subject "国語" --year 2025 --round "第1回"
```

開いた専用Chromiumで東進学力POSにログインし、**共通テスト対策 → 問題印刷**のページを表示してください。印刷画面を開くたびに、ページに記載されたPDFダウンロードリンクから1件ずつ取得します。画面を閉じる必要はありません。終了はターミナルで `Ctrl+C`。

**重要:** `--subject` は必須です。科目を変えるときは停止して新しい科目で起動してください。印刷ページ単体では科目名を取得できないことがあるためです。

### 2. PDFを2-in-1に変換して保存

```bash
npm run process
```

保存先は `.local/output/{科目}/` です。出力例: `2025_国語_第1回_問題_DBB060608_a1b2c3d4.pdf`。最後の英数字は識別用で、ファイル名の衝突を防ぎます。初回保存時の原本は `.local/raw/` に残ります。処理済みPDFは再実行時にスキップします。

```bash
npm run process -- --force
# 年度・回次・科目を補正するには --force と共に指定
npm run process -- --force --subject "国語" --year 2025 --round "本試"
npm test
```

全成果物を置くフォルダを変える場合は `--data-dir /任意の保存先` を両コマンドに指定してください。

## 注意事項

- **PDFやログイン状態はGitHubへアップロードしません**。 `.local/` は `.gitignore` で除外します。
- 認証回避、ログインの自動突破、IDの総当たり、トークン生成の推測は実装しません。
- ダウンロードURLの `daimonId` は不透明な値です。短期失効や署名の有無は未検証なのでURLを保存・再利用せず、表示された時点で取得します。
- ページによって表示するデータが異なる場合や認証エラーが発生した場合はスキップしてログに知らせます。
- 自動取得を行う範囲・頻度は東進本部から許可された個人利用に限ります。
- PDFの著作権・使用条件は原提供者に帰属します。第三者への再配布を想定しません。

## トラブルシューティング

- PDFが保存されない場合、ログイン状態を確認し印刷画面を開き直してください。期限切れや認証エラーでは新しいリンクが必要です。
- `npm run capture` は印刷画面ごとの手動操作が必要な従来コマンドです。一括取得には `npm run year` または `npm run daimon` を使用してください。
- 同じ `--data-dir` に対して複数プロセスを同時起動しないでください。履歴の同時更新はサポートしていません。
- カスタム保存先はGit管理外に置き、ブラウザプロファイル、履歴、PDFを共有しないでください。
- PDFのレンダリングテストには `pdftoppm` が必要です。未インストールの場合、そのテストはスキップされます。実物の表示・印刷も確認してください。

## GUIで取得する

### Macではダブルクリックで起動

リポジトリの `東進PDFを起動.command` をダブルクリックしてください。初回は必要なパッケージと専用ブラウザをインストールします。Node.js 20以上とインターネット接続が必要です。起動中は開いたターミナルを閉じないでください。終了はブラウザを閉じるか、ターミナルで `Ctrl+C` です。

macOSで開発元を確認できない旨が表示された場合は、FinderでファイルをControlキーを押しながらクリックし、「開く」を選択してください。実行権限が失われている場合は、ターミナルで `chmod +x 東進PDFを起動.command` を実行してください。保存先やデータの移動は行いません。ファイルはこのリポジトリのフォルダ内に置いたまま使ってください。

### ターミナルから起動

```bash
npm run gui
```

専用ブラウザに「東進 PDF 整理」とPOSのタブが開きます。POSタブで本人がログインし、GUIタブに戻って「年度別を読み込む」を押すと年度・科目の一覧が出ます。大問別はPOSで科目・分野の問題一覧を開いた後、「大問別を読み込む」を押してください。科目は画面の分野名から自動判定します。判別できない場合だけ入力してください。

候補はチェックボックスで複数選択でき、絞り込みと表示中の全選択も使えます。「選択した問題を取得」を押すと進捗・保存・スキップ・失敗件数を表示します。大問別は1問ごとに個別PDFを保存します。対象を再取得すると保存済みのものはスキップされます。終了するにはブラウザを閉じるか、起動したターミナルで `Ctrl+C` を押してください。保存先を指定する場合は `npm run gui -- --data-dir /保存先` を実行します。

## 大問別演習を1問ずつ保存（CLI）

```bash
npm run daimon
```

専用Chromiumで本人がログインし、「過去問演習講座 共通テスト対策 → 大問別演習」で指定科目の分野を開きます。問題一覧を開いたら、ターミナルで Enter を押します。表示された一覧から `1,3-8` のように番号や範囲を入力して任意の件数を選択できます。`a` で表示中の分野の全問題を選択できます。POS画面でチェックを入れる必要はありません。対象は順番に1問ずつ選び直して正規の印刷画面を開き、各問題を別々のPDFにします。`q` で終了します。ログインが切れた場合は専用ブラウザで再ログインしてください。

科目は一覧の分野名から自動判定します。判別できない場合は入力を求めます。必要な場合は `--subject 国語` のように明示もできます。国語は右→左、それ以外は左→右の2-in-1になります。出力先は `.local/output/科目/分野/` で、例は `01-大問別演習　国語　現代文・評論　1812.pdf` です。POSの問題名をそのまま使用し、ファイル名に使えない文字は置換します。同名衝突時は識別子を加えます。`--data-dir /任意の保存先` で保存先を変更できます。

取得履歴は `daimon-manifest.json` に記録します。同じ分野・問題で出力が残っていれば再実行時にスキップし、途中で止まった場合も再開できます。1件ずつ取得し、間隔を空けてアクセスします。取得に失敗した場合は残りを中断するので、認証状態やサイトの状況を確認してから再実行してください。同じ保存先を複数プロセスで同時に使わないでください。問題PDF、ブラウザプロファイルと取得履歴は個人用として管理し、Gitに追加しないでください。カスタム保存先もGit管理外に置いてください。

## 年度別演習を自動取得

```bash
npm run year
```

専用ブラウザで本人がログインして学習メニューを表示したら、ターミナルで Enter を押します。年度別演習の一覧を自動で開き、取得できる年度・試験区分・科目を番号付きで表示します。`1,3-8` のように番号と範囲を組み合わせるか、`a` で全件を選びます。指定件数に制限はありません。取得は順次行い、失敗時には残りを中断します。再実行すると保存済みのものをスキップします。

保存先は `.local/output/年度別/科目/`、名前は `2025_国語 (現古漢）_本試_問題.pdf` などです。画面の科目名を使い、重複名には識別子を付けます。`--data-dir /保存先` で保存場所を変更できます。現時点ではPOS側で表示されている科目のみが候補です。
