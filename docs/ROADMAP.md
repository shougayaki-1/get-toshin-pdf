## 実サイトで最初に試すこと

1. `npm install && npx playwright install chromium`
2. `npm test`
3. `npm run capture -- --subject 国語 --year 2025 --round 本試`
4. ログインして該当する問題印刷ページを開き、標準出力の保存件数を確認。
5. `npm run process` で出力PDFの並び・文字の欠け・用紙サイズを確認。
6. 取得不能ならブラウザのNetworkで**PDF URLの共有は避け**、HTTPステータス・レスポンスのContent-Type・ブラウザ操作のみ確認。
