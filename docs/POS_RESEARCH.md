# 学力POS実画面の観察メモ（2026-11-04）

## 実際にログイン状態のChromeタブで確認した事実

- POSには「過去問演習講座 / 共通テスト対策」メニューがあり、メニュー項目のリンクにはASP.NET Web Formsの `javascript:__doPostBack(...)` 形式が使われる。
- 問題ページのタイトルは「問題解答印刷 | 東進学力POS」。
- 印刷ページのパスは `/TGT/OPCTTS/OPCTTS_Student/MondaiKaitoInsatsu` で、クエリに `EnshuSetId` と `DaimonId` が付く。
- 「PDFダウンロード」リンクは `/TGT/OPCTTS/OPCTTS_Student/Contents/GetMondaiPdf?daimonId=...`。
- 印刷ページの `DaimonId` とダウンロードリンクの `daimonId` は表記・値が異なる（変換規則は未確認）。
- 同じ印刷ページには「解答用紙印刷」ボタンがあるが、こちらの動作やPDFエンドポイントは未確認。初期版は問題のみを対象にする。

## 未確認事項と検証方法

- **年度・科目の一覧画面**: ブラウザから該当画面を閲覧してDOMとページ遷移を確認する。
- **PDFリンクの有効期限・署名・トークン形式**: 推測しない。実際のリンクをブラウザ文脈で取得する。
- **PDF応答の形式**: Playwrightの専用セッションで動作確認。内容がPDFでない場合は安全に拒否する。
- **解答用紙と解答解説**: 追加要件として別途調査。初期版には含めない。
- **自動科目判定**: 印刷ページ単体の表示では科目が確実にわからないため、初期版は `--subject` 指定。

### 個人情報・認証保護

観察した実際の学生ログインID、opaqueなPDFダウンロードパラメータ、Cookie値、hidden fieldは**このリポジトリには記載していない**。実際のセッションを復元できるデータは収集・公開しない。
